A Python 3.13 standard-library program that draws a 1024x1024 front-page image summing up the world news of Wednesday 18 November 2026: Nvidia's earnings beat and the Asia rally, the second strike on the Kerch Bridge, the Bahrain all-clear after Iranian attacks, the Quad meeting in Manila, Anthropic's IPO pricing, and MS Dhoni's retirement from the IPL. It writes the image to `/output/entry.png`. No network access; fully deterministic — every run writes identical bytes.

## Run it

mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
